# HR Analytics Dashboard | Power BI

## 📌 Project Overview
An interactive HR Analytics Dashboard developed using Power BI to analyze workforce distribution, employee demographics, salary, attendance, training, performance, and promotion-related metrics.

## 🎯 Project Objectives
- Monitor overall employee and department metrics.
- Analyze employee distribution by state, gender, job role, education, and marital status.
- Explore salary patterns across job roles and experience groups.
- Evaluate attendance, performance ratings, training hours, and overtime.
- Track promotion eligibility and promotion status using interactive visualizations.

## 🛠️ Tools & Technologies
- **Power BI** — Dashboard design and data visualization
- **DAX** — HR measures and KPI calculations
- **Data Modeling** — Relationships between employee, department, and performance data

## 📊 Dashboard Pages

### 1. Executive
- Workforce KPIs and hiring trends
- Employee distribution by state and gender

### 2. Employee Analysis
- Salary and experience analysis
- Employee demographics and training

### 3. P&A Analysis
- Attendance and performance analysis
- Promotions and overtime insights

## 🔍 Key Features
- KPI cards for key HR indicators
- Interactive slicers and visualizations
- Employee, department, and performance analysis
- Comparisons across job roles, experience groups, and departments
- A consolidated view of workforce metrics for HR analysis
